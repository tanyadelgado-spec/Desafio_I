# -_-_-_- Sweet Crush -_-_-_-

**Sweet Crush** es un juego desarrollado en C++ utilizando Qt Creator. El objetivo del juego es lograr combinaciones de tres o mas fichas, a través de la manipulacion del tablero, obteniendo puntos por estas o por eliminaciones puntuales.
El proyecto busca aplicar conceptos de almacenamiento a nivel de bits, punteros, funciones, manejo de memoria dinámica y estructuras de control.

---

## _-_-_-_ Características _-_-_-_

* Tablero de juego con 6 tipos de fichas diferentes.
* Detección de combinaciones de fichas.
* Eliminación de combinaciones.
* Caída de las fichas para llenar los espacios vacíos.
* Generación de nuevas fichas.
* Sistema de puntuación.
* Representación visual de las diferentes fichas.

---

## _-_-_-_ Instrucciones de Juego _-_-_-_

El jugador debe establecer las dimensiones iniciales del tablero; elige la opción del menú que prefiera para ir interactuando con el tablero, siendo estas eliminar ficha, agregar/eliminar una fila o columna, y así lograr armar combinaciones de tres o más fichas iguales, las cuales se eliminarán.
Después, las fichas que están encima bajan para ocupar los espacios vacíos, se generan nuevas fichas para completar el tablero, se verifica nuevamente si existen combinaciones hasta que ya no hayan más combinaciones posibles, dando espacio a que el jugador seleccione una nueva opcion en el menú.

El objetivo es conseguir la mayor cantidad de puntos posible.
